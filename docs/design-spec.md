# Andigo — Спецификация дизайна лендинга

## Дата: 2026-03-31
## Статус: утверждён пользователем, реализация не начата

---

## Концепция: "ASCII Cinema / Darknet Gateway"

Лендинг в стиле **входа в даркнет**: чёрный экран, символы ASCII плывут/мерцают фоном, поверх — чистая белая типографика. Ощущение: ты открыл терминал в другой реальности.

### Настроение и референсы
- Вход в даркнет / deep web
- ASCII-видео (символы складываются в образы, анимированно текут)
- Чёрно-белый монохром с лёгкими акцентами
- Кинематографичность: как заставка к фильму про хакеров
- Референсы: three.js ASCII effect, brutalist monochrome sites, terminal aesthetics

### Палитра
- Фон: `#000000` (чистый чёрный)
- Текст основной: `#ffffff`
- ASCII-символы фона: `#1a1a1a` → `#333333` (едва видимые, мерцающие)
- Акцент (минимально): `#00ff41` (matrix green) ИЛИ без акцента, чистый ч/б
- Разделители/рамки: `#222222`

### Шрифты
- **ASCII/фон:** `'Courier New', 'Lucida Console', monospace` — или кастомный моноширинный (JetBrains Mono, Fira Code)
- **Заголовки:** Жирный гротеск — `Space Grotesk`, `Inter Black`, или `Monument Extended` (если подключить)
- **Тело текста:** `Inter`, `Space Grotesk` — чистый, современный sans-serif
- **Размеры:** Заголовок hero: 64-80px desktop, 36-48px mobile

### Структура лендинга

#### 1. Hero секция (полный экран)
- **Фон:** Canvas/div с ASCII-анимацией — символы (`.:;+=xX$&#@%`) медленно текут сверху вниз (как Matrix, но медленнее и тоньше)
- **По центру:** Логотип "ANDIGO" — крупный, жирный, с лёгким glow-эффектом
- **Подзаголовок:** "Приватный доступ к интернету" (НЕ слово "VPN")
- **CTA кнопка:** "ПОДКЛЮЧИТЬСЯ" — рамка из символов или чистая белая рамка
- **Внизу:** стрелка вниз или hint "scroll"

#### 2. Фичи (3 карточки)
- На чёрном фоне, карточки с лёгкой рамкой `#222`
- Иконки — ASCII-арт (замок из символов, молния из символов, глобус из символов)
- **Тексты (юридически корректные):**
  - "Шифрование трафика" (не "обход блокировок")
  - "Серверы в нескольких странах" (не "анонимность")
  - "Высокая скорость соединения"

#### 3. Тариф
- Одна карточка по центру, стиль "терминал"
- `249 ₽/мес` — крупно
- Список: все серверы, безлимит, до 3 устройств
- CTA: "НАЧАТЬ"

#### 4. Как подключиться (3 шага)
- ASCII-нумерация: `[01]` `[02]` `[03]`
- Шаги: Регистрация → Оплата → Скачай приложение и вставь ключ

#### 5. Футер
- Минималистичный: © 2026 Andigo
- Ссылки: Telegram-бот, поддержка

### Анимации
- **ASCII rain (фон hero):** Canvas, символы падают как в Matrix но тише (opacity 0.05-0.15)
- **Typing effect:** Подзаголовок печатается как в терминале
- **Fade-in секций:** При скролле секции плавно появляются
- **Hover на кнопках:** Символы ASCII "пробегают" по рамке

### Технические заметки
- Анимация ASCII — через HTML Canvas (НЕ three.js, экономим размер бандла)
- Responsive: мобильная версия — уменьшить/упростить ASCII-фон
- Шрифты: Google Fonts (Space Grotesk + JetBrains Mono) или self-hosted
- Без внешних зависимостей кроме React + Tailwind (уже есть)
- Производительность: requestAnimationFrame, уменьшить плотность символов на мобильных

### Юридические заметки (формулировки)
- **Использовать:** "приватный доступ", "защищённое подключение", "шифрование", "безопасный интернет"
- **НЕ использовать:** "VPN" (минимизировать), "обход блокировок", "анонимность", "доступ к заблокированным сайтам"
- На сайте слово "VPN" можно упомянуть 1 раз мелко в описании технологии, не в заголовках

### Файлы для изменения
- `frontend/src/pages/Landing.tsx` — полная переделка
- `frontend/src/index.css` — глобальные стили, шрифты
- `frontend/tailwind.config.js` — обновить цветовую палитру
- Возможно новые компоненты: `AsciiRain.tsx`, `TypingText.tsx`

### Остальные страницы
- Login.tsx, Register.tsx — тот же чёрный стиль, минималистичные формы
- Dashboard, Servers и т.д. — тёмная тема, но без ASCII-анимаций (чтобы не мешали)
- Общая тема: чёрный фон, белый текст, моноширинный шрифт для данных
