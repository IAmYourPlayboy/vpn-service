# Andigo — Спецификация редизайна фронтенда

## Дата: 2026-03-31
## Статус: дизайн утверждён, реализация не начата

---

## Контекст

Пользователь недоволен текущим визуалом фронтенда:
- ASCII Rain на hero выглядит плохо (серый мусор, падающие символы не красиво)
- ASCII-иконки в карточках фичей неуклюжие
- Нет анимаций на карточках фичей (кроме ScrambleText на ховер)
- Земля на Login/Register статичная и маленькая
- Кнопка "Вернуться" внизу формы вместо левого верхнего угла
- Dashboard слишком простой
- Чёрный фон на секциях (фичи, тариф, шаги) скучный

---

## Утверждённые решения (из брейншторма)

### 1. Hero-фон: Hex Matrix Rain (Canvas)
- **Набор символов:** `0123456789ABCDEF` (шестнадцатеричные, НЕ японские)
- **Реализация:** Canvas с requestAnimationFrame
- **Затухание:** rgba(0,0,0,0.06) — чистый фон, быстрое исчезновение следов (НЕ серый мусор)
- **Яркость символов:** max 0.10-0.12 opacity, редкие вспышки до 0.35
- **Скорость:** средняя, переменная (0.2 + random * 0.5)
- **Ассоциация:** дамп памяти, сетевой трафик, техничный хакерский вид
- **Заменяет:** текущий компонент AsciiRain.tsx (CSS-анимация → Canvas)

### 2. ASCII-иконки: Block/Shadow стиль (█▓▒░)

**Замок (шифрование) — утверждён:**
```
     ▄██▄
     █  █
  ▄████████▄
  █ ▒▒▒▒▒▒ █
  █ ▒▒▒▒▒▒ █
  █ ▒▒▒▒▒▒ █
  ▀████████▀
```

**Молния (скорость) — вариант B, градиент:**
```
 ▓███▀▀
  ▓██▀
  ▀██▓
▀▀▀▀▀▀▀▀▀
   ▀██▓
    ▀█▓
     ▀▓
```

**Серверная стойка (серверы) — вариант A:**
```
  ▄████████▄
  █ ▪▪▪▪ ░░ █
  ▀████████▀
  ▄████████▄
  █ ▪▪▪▪ ░░ █
  ▀████████▀
```

### 3. Анимации карточек фичей (последовательные)

Все три карточки анимируются **автоматически** (не на ховер), **друг за другом** с задержкой ~1-2 сек между карточками. Используется IntersectionObserver — запуск при появлении в viewport.

**Карточка "Шифрование трафика":**
- Анимация: `0` и `1` случайно меняются в тексте описания
- Скорость: чуть медленнее текущего ScrambleText (~40-50ms вместо 25ms)
- Визуально: текст описания периодически "мерцает" бинарными символами

**Карточка "Высокая скорость":**
- Анимация: молниеносная — текст описания печатается мгновенно (typing effect, 10-15ms/символ)
- Дополнительный элемент: под описанием появляется строка вроде `> ping: 12ms ✓` или `> Время отклика: 30 мс` в моно-шрифте
- Ощущение: "это очень быстро"

**Карточка "Серверы в нескольких странах":**
- Анимация: текст описания "стирается" посимвольно (как backspace в терминале), затем печатается заново на другом языке
- Языки: русский → английский → немецкий → французский → снова русский
- Варианты текста:
  - RU: "Подключайтесь к ближайшему серверу"
  - EN: "Connect to the nearest server"
  - DE: "Verbinden Sie sich mit dem nächsten Server"
  - FR: "Connectez-vous au serveur le plus proche"
- Скорость удаления: ~20ms/символ, скорость печати: ~40ms/символ

**Порядок:** Шифрование → (задержка 1.5с) → Скорость → (задержка 1.5с) → Серверы. После завершения цикла — пауза 3с и повтор.

### 4. Login/Register: вращающаяся ASCII-Земля

- **Расположение:** правая часть экрана (desktop), форма — слева
- **Земля:** большая, close-up, видна примерно 60-70% планеты от правого края
- **Вращение:** медленное, ~30 секунд на оборот
- **Реализация:** массив pre-rendered ASCII-кадров (10-20 кадров), циклическая смена через setInterval
- **Фон слева:** чёрный = "космос". Можно добавить редкие точки-звёзды (статичные `.` символы разной яркости)
- **На мобильном:** Земля скрыта (как сейчас)
- **Кнопка "Вернуться":** переместить в ЛЕВЫЙ ВЕРХНИЙ УГОЛ (сейчас внизу формы). Стиль: `← Назад` или `← Вернуться`, position absolute top-left
- **Форма:** остаётся слева, по центру вертикально

### 5. Dashboard: терминальный стиль + виджеты

**Визуальный стиль:**
- Терминальная эстетика: моно-шрифт, рамки из `─│┌┐└┘`, зелёные/белые акценты
- Заголовки секций как терминальные команды: `$ status`, `$ servers`, `$ vpn`

**Виджеты (расширенный функционал):**
1. **Статус подписки** — карточка с оставшимися днями, прогресс-бар из блочных символов (▓▒░), дата истечения
2. **Быстрое подключение** — QR-код + ссылка + кнопка копирования (как сейчас, но в терминальном стиле)
3. **Мини-статус серверов** — 2-3 ближайших сервера с пингом, ссылка "все серверы →"
4. **Уведомления** — если подписка истекает через 3 дня, показать предупреждение

**Layout:** grid 2 колонки на desktop, 1 на mobile.

### 6. Фон секций (не-hero)

Добавить субтильную текстуру на секции фичей, тарифа, шагов:
- Вариант: очень тусклая (opacity 0.02-0.03) сетка точек или ASCII-символов
- Или: едва заметный gradient noise
- Цель: не плоский чёрный, а с "глубиной"

### 7. Sidebar / Layout

Привести к терминальному стилю:
- Заменить emoji-иконки (🏠🌍💳⚙️) на ASCII/текстовые: `[~]` `[>]` `[$]` `[*]`
- Или использовать моно-символы: `⌂` `◎` `◆` `⚙`
- Стиль NavLink: `> Главная` вместо `🏠 Главная`

## Технические заметки

- Все анимации Canvas — requestAnimationFrame
- ASCII Earth: pre-rendered кадры (не real-time рендеринг — экономия CPU)
- IntersectionObserver для запуска анимаций карточек при скролле
- Анимации карточек последовательные (не параллельные) — staggered delay
- Mobile: упрощённые версии (меньше кадров Earth, меньше колонок Rain)
- Без новых зависимостей (всё на React + Canvas + CSS)
